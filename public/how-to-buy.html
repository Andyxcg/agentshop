Why

Retrieval and analysis agents frequently need structured macroeconomic data — GDP, inflation, trade, debt, labour, energy, emissions — across many countries and years. Most sources hide it behind login walls or per-seat SaaS contracts that an autonomous agent cannot sign. agentshop exposes the same data through a machine-native payment rail: an HTTP 402 carries the exact price, the buyer signs one USDC transfer, and the report is served. No human, no account, no fiat on-ramp.

The flow in three steps

1
Search for free. Find the report id by keyword — GDP, "renewable energy", "2024 economy". 
curl https://reportbazaar.app.workbuddy.host/search?q=inflation
2
Preview for free. Fetch the latest year for every economy in the exact field names the paid payload uses, so the agent can verify coverage before paying. 
curl https://reportbazaar.app.workbuddy.host/preview/macro-inflation
curl https://reportbazaar.app.workbuddy.host/preview/macro-inflation?format=csv
3
Pay and fetch. Request the paid report; the 402 response carries the exact x402 payment requirements (amount, asset, network, payTo, facilitator). Sign one USDC transfer, replay the same request with the payment header, and receive the report in HTML, JSON or CSV. 
# First call returns 402 + x402 payment requirements
curl https://reportbazaar.app.workbuddy.host/report/macro-inflation?format=json
# Sign the quoted USDC amount, then replay with the payment proof:
curl -H "X-PAYMENT: <signed-payment-header>" \
     https://reportbazaar.app.workbuddy.host/report/macro-inflation?format=json
Any x402 client library (e.g. x402 for TypeScript/Python) automates steps 3's sign-and-replay.

Via MCP (Model Context Protocol)

An MCP-aware runtime can install agentshop as a tool source with no human reading a README. The free tools answer inline; the paid tool returns the exact quote so the runtime can decide to pay.

{
  "mcpServers": {
    "agentshop": {
      "url": "https://reportbazaar.app.workbuddy.host/mcp"
    }
  }
}

Tools: search_reports, list_catalog, list_years, preview_report (all free), report_payment_requirements (quote), and buy_report (resolve delivery URL + x402 requirements). Pass id="bundle" to the quote/buy tools for the full-catalog bundle — every report in one payment.

Pricing

Single reports: $0.05–$0.95 USDC, quoted live in the 402.
Full-catalog bundle: one x402 payment unlocks all 171 reports at a steep discount to buying them separately.
Category bundles: buy one theme (e.g. energy, trade) for less.
Nothing costs more than $0.95 — buyer libraries apply a $1 per-payment spend cap.

Best value

If you need breadth across the catalog, buy the bundle first — it is cheaper than two single reports and one signature covers the whole dataset. Single reports and /report/custom remain the right call for narrow, one-off questions. Every report is generated on demand from the World Bank API, so freshness tracks the source.
